# Local business website demos

Phone-ready, one-page concepts for eight businesses in the Orlando area. Static HTML, CSS, and vanilla JavaScript, meant to be served from GitHub Pages at the repository root.

- [Bossa Nova Brazil Market & Café](bossa-nova/)
- [Elite Barber Studio Inc.](elite-barber/)
- [Nelquan's Touch Barber Shop](nelquans-touch/)
- [Posh Nails Winter Park](posh-nails/)
- [Bill's Men's Hair Styling](bills-mens-hair/)
- [Mini's Nails Spa](minis-nails/)
- [Springfield Dry Cleaner & Tailors](springfield-cleaners/)
- [Quality Cleaners / $2.79 Cleaners](quality-cleaners/)

Every page sends `noindex`. These are demo concepts by Kai Au and are not the businesses' official sites.
